# TAKANE-SHIKI GOLDEN RULES

日本語 × English × සිංහල の 文型集。スリランカの学習者向け。

**124 単元 / 208 ページ　—　N5 58単元・N4 65単元・巻末 1単元**

- 各ページ：基本フレーズ → つかいかた → 基本パターン → 例文7つ
- 全文にふりがな・ローマ字・英語・シンハラ語
- A4 印刷前提（1単元＝1ページ、第1章のみ 1単元＝5ページ）
- JLPT N5・N4 の文法をカバー。JFT-Basic（特定技能）で使う単元にはマーク付き

## リポジトリの中身

```
├─ src/                 ページを生成する Python
│   ├─ build.py           文型ページの生成器（CSS・レイアウト・自動フィット）
│   ├─ build2.py          資料ページの生成器（かな表・数字・時間 など）
│   ├─ plan124.py         124単元の順番（マスター）
│   ├─ levels.py          単元ごとの N5/N4 と JFT-Basic 判定
│   ├─ scenes.py          単元ごとの場面タグ（面接・仕事・買い物 …）
│   ├─ build_all.py       ぜんぶ生成して dist/ に出す
│   └─ data_01.py 〜 data_124.py    各単元の中身（例文はここ）
├─ units.json           サイト用メタデータ
├─ CONTENTS.md          目次（レベル・JFT・場面タグ入り）
└─ dist/                生成物（git には入れない）
```

`dist/` は `.gitignore` に入れてあります。PDF は Releases に置くか、
手元でビルドしてください。

## ビルドのしかた

必要なもの：Python 3、`pymupdf`、Chromium、Noto Sans CJK JP、Noto Sans Sinhala

```bash
pip install pymupdf
sudo apt-get install -y fonts-noto-cjk fonts-noto-core chromium

cd src
python3 build_all.py            # 全124単元 → dist/
python3 build_all.py --merge    # 生成済みのページを結合するだけ（速い）
```

出力：

| ファイル | 中身 |
|---|---|
| `dist/TAKANE_GOLDEN_RULES_124.pdf` | 通し208ページ（しおり付き） |
| `dist/units/unit_001.pdf` 〜 `unit_124.pdf` | 単元ごとの PDF |
| `dist/html/` | 同じ内容の HTML（CSS 埋め込み済み） |
| `units.json` | メタデータ（再生成される） |

`build.py` の `CHROME` のパスは環境に合わせて直してください。

## 中身を直したいとき

例文を1つ変えたい → `src/data_50.py` のような単元ファイルを開いて、
`examples=[...]` の該当行を書き換えて `python3 data_50.py` を実行。
その単元の PDF だけ作り直されます。

タイトル・レベル・場面タグを変えたい：

| 変えたいもの | 直すファイル |
|---|---|
| 単元の順番・タイトル | `src/plan124.py` |
| N5 / N4 の判定、JFT マーク | `src/levels.py` |
| 場面タグ | `src/scenes.py` |
| 色・フォント・レイアウト | `src/build.py` の `CSS` |

## units.json

サイトで使うためのメタデータです。1件はこの形：

```json
{
  "no": "50",
  "order": 50,
  "chapter": "第3章 すき・くらべる",
  "title_jp": "〜した ほうが いいです",
  "level": "N4",
  "jft_basic": true,
  "scenes": ["病院", "仕事", "友だち"],
  "prereq": ["49"],
  "pages": { "start": 76, "count": 1 },
  "stems": ["u50_hougaii"]
}
```

| キー | 使い方 |
|---|---|
| `order` | 学習順。昇順に並べればそのまま積み上げになる |
| `level` | `"N5"` / `"N4"` / `"GUIDE"`。学習者のレベルで出し分け |
| `jft_basic` | JFT-Basic（特定技能）で直接つかう単元か。全124中101 |
| `scenes` | 場面タグ。`"面接"` で絞ると面接に必要な20単元が出る |
| `prereq` | この単元より前に必要な単元。全部完了していればロック解除 |
| `pages` | 通し PDF の該当ページ（`start` 〜 `start + count - 1`） |

場面タグは11種：面接 / 仕事 / 学校 / 買い物 / 食事 / 道・交通 / 病院 / 役所 / 電話メール / 友だち / 文字
